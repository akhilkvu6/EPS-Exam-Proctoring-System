F. Destructive Action Confirmation Demonstrations

Strict visual hierarchy for irreversible destructive operations: always pairing a prominent neutral Grey Cancel button with a high-contrast Red confirmation button and clear explanation of consequences.

1. Delete User Account

Permanently deletes user credentials, exam enrollment history, and grade records. Irreversible.

2. Delete Examination

Cancels test paper, purges all candidate answer sheets and proctoring telemetry snapshots.

3. Revoke Access

Immediately terminates active session token, ejecting user from the invigilation room.

4. Force End Examination

Auto-submits all in-progress student sessions and locks the examination room immediately.

5. Permanently Delete Records

Purges archived student logs, invigilator audit trails, and forensic video snapshots.
