Template Guide 📋

Required Columns:

  • subject_code: Course code matching registered Subject (e.g., CS101).
  • question_type: mcq, true_false, or short_answer.
  • question_text: Complete question prompt.
  • marks: Decimal or integer points (e.g. 2.0).
  • negative_marks: Penalty points (e.g. 0.5).
  • difficulty: easy, medium, or hard.
  • option_a to option_d: Multiple choice alternatives.
  • correct_option: Key identifier (A, B, True, etc.).
