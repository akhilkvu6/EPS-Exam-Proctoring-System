Institutional Disaster Recovery Procedure

To restore the examination platform to a verified baseline in the event of hardware or storage failure:

  1. Stop the running Django application server.
  2. Copy the desired snapshot (e.g., db.sqlite3.backup_change_request) to db.sqlite3.
  3. Run python manage.py check to ensure relational integrity is satisfied.
  4. Restart the application server. All user accounts, examination papers, and proctoring telemetry will resume immediately.
